# TBARC Academy

Initial public-facing website for TBARC Academy.

## Files
- `index.html` – Homepage
- `courses.html` – Course catalogue placeholder
- `login.html` – Participant login placeholder
- `dashboard.html` – Participant dashboard placeholder
- `assets/css/style.css` – Responsive styling
- `assets/js/app.js` – Navigation and small UI behaviours
- `assets/images/` – Temporary logo and favicon

## Deployment
1. Upload all files and folders to the root of the `TBARC-Academy` repository.
2. In GitHub, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch `main` and folder `/ (root)`, then Save.

Firebase authentication, Firestore enrollment checks and private Google Drive permissions are not connected yet. The login button is intentionally disabled until those security features are implemented.
